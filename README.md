## Local Development

```bash
# Clone the repository
git clone [https://github.com/iggym/fde-field-notes.git](https://github.com/iggym/fde-field-notes.git)

# Navigate to the directory
cd fde-field-notes

# Serve locally (requires Python)
python3 -m http.server 8000
